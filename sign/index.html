✅ 最初に守るルール

お客様の「シール」「看板」「プレート」は、正しい商品名とは限りません。スタッフも最初から分類できなくてOKです。

基本方針: 商品名を決めつけず、写真で近いものを確認してから用途を聞く。
禁止: 金額・納期を電話で即答しない。商品名を決めつけて見積に進まない。
ゴール: スタッフが詳しくなることではなく、正しく聞いて、ベスタbotへ投げられること。

⚙️ 制作する機械設備を知る
UVプリンター
  • 紫外線でインクをすぐ硬化させ、アクリルなどの平面素材へ直接印刷する。
  • アクリルプレート、案内板、許可票、小型サインに向く。
  • 厚み・素材・印刷面が平らかどうかを確認する。
大判インクジェットプリンター
  • 塩ビシートなどへ大きく印刷する機械。写真・フルカラー看板に使う。
  • 屋外ステッカー、アルミ複合板看板、ポスター、大判出力の入口になる。
  • サイズ、屋外使用、貼る素材、色数ではなくフルカラーかを確認する。
大判ラミネーター
  • 印刷したシートの表面を保護する透明フィルムを貼る。
  • 屋外看板、車両ステッカー、マグネットなどの耐候性を上げる。
  • つやあり、つやなし、長期使用か短期使用かを確認する。
カッティングプロッター
  • 色付きシートを文字やロゴの形に切る。写真印刷とは別の作り方。
  • ガラス文字、車名入れ、入口表示、注意表示に使う。
  • 細かすぎる文字、グラデーション、写真は苦手。データの形が重要。
のぼり・横断幕の出力加工
  • 布や幕素材へ印刷し、ハトメ、棒袋、ロープなどの加工を行う。
  • 店頭販促、イベント、応援幕、壁面掲示に使う。
  • 設置方法を聞かないと、必要な加工や付属品が決められない。
マグネットシート加工
  • 印刷シートをマグネットへ貼り、必要な形にカットする。
  • 営業車、仮設表示、ホワイトボード用の表示に使う。
  • 車に使う場合は、貼る面が磁石につくかを必ず確認する。
🛠️ 商品の作り方をざっくり知る

スタッフは職人レベルまで覚えなくてOKです。ただし、作り方を少し知ると「なぜ確認が必要か」が分かります。

商品ざっくりした流れ見積前に大事な確認
アルミ複合板看板 デザイン作成 → 塩ビシートに印刷 → ラミネート → 板に貼る → カット・穴あけ → 納品または施工 サイズ、屋外、取付場所、穴あけ、施工の有無。
カッティングシート データ作成 → シートを機械でカット → 不要部分を剥がす → 転写シートを貼る → 貼付または納品 貼る場所、色、文字サイズ、細かさ、内貼り・外貼り。
アクリルプレート 素材選定 → デザイン作成 → UV印刷またはシート貼り → カット・穴あけ → 金具や両面テープ準備 透明/白/黒、厚み、屋内外、取付方法。
のぼり・横断幕 サイズと生地を決める → データ作成 → 出力 → ハトメ・棒袋など加工 → 付属品確認 屋外、設置方法、ハトメ位置、ポールやロープの有無。
マグネットシート デザイン作成 → 印刷 → ラミネート → マグネットへ貼る → カット → 使用面の確認 貼る面が鉄か、車両用か、サイズ、貼りっぱなしにするか。

お客様の言葉候補最初に聞くこと
シールカッティングシート、ステッカー、看板用シート、マグネットどこに貼るか。文字だけか、写真・フルカラーか。何枚必要か。
看板アルミ複合板、アクリルプレート、横断幕、のぼり、マグネットどこに設置するか。屋内/屋外。板か布か、貼るだけか。
プレートアクリルプレート、表札、案内板、許可票、アルミ複合板サイズ、厚み、取付方法、屋内/屋外、表示内容。
幕横断幕、タペストリー、のぼり、大判出力吊るす場所、サイズ、ハトメ・棒袋、屋外使用か。
車に貼るやつカッティングシート、マグネットシート、ステッカー貼りっぱなしにするか、外せるようにするか。貼る車の面。
❓ まず聞くこと
  1. どこに使いますか？ 店舗、車、窓、壁、屋外、イベントなど。
  2. 屋内ですか、屋外ですか？
  3. 一時的ですか、長期使用ですか？
  4. 貼る面・取り付ける面は何ですか？ ガラス、壁、車、鉄、看板、商品、紙など。
  5. サイズはどれくらいですか？ 縦横の目安でOK。
  6. 何枚、何個、何本必要ですか？
  7. 文字だけですか、ロゴや写真、フルカラーがありますか？
  8. データはありますか？ イラストレーター、PDF、画像、手書きなど。
  9. 自分で貼りますか、施工も必要ですか？
  10. 希望納期はいつですか？ 使用日が決まっているか確認する。
💬 お客様への返答例
「シールを作りたい」と言われた時
「シール」といっても、商品に貼るステッカー、窓ガラスに貼る文字、看板用のシート、車に貼るマグネットなど種類が分かれます。まず、どこに貼る用途か教えていただけますか？
「看板はいくら？」と言われた時
看板は、使う場所、サイズ、素材、取付方法、データの有無で金額が大きく変わります。お電話口では正確に判断しにくいため、設置場所・サイズ・使用目的をフォームからお送りください。
写真で確認する時
この中だと、どの写真に一番近いですか？ 近いものが分かれば、必要な確認項目を絞ってご案内できます。
