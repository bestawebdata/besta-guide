# 納期表ポスター イラスト作成 指示書（ChatGPT用）

対象：`intake-rules/delivery-notice.html`（店頭掲示用 納期表・A4縦）
作成日：2026年7月31日

---

## 0. 最初に読むこと

**ChatGPTに日本語の文字を書かせないでください。**

AI画像生成は日本語の文字が高確率で崩れます。実在しない漢字、意味の通らない仮名、途中で切れた単語になります。
お客様に配るものでこれをやると、印刷店として信用を落とします。

> このマニュアル自体に「AIデータは日本語の文字が崩れていることがある」と書いてあります。
> 自社の掲示物で同じことをしないでください。

**やること：ChatGPTには「絵」だけを作らせる。文字はHTMLに入っているものをそのまま使う。**

これなら文字は絶対に崩れず、レイアウトも崩れません。

---

## 1. まずこれを貼る（スタイル指定）

ChatGPTの新しいチャットを開いて、最初にこれを貼ってください。

```
印刷会社の店頭に貼るA4ポスター用の、アイコン風イラストを作ってもらいます。
これから1点ずつ指示するので、以下のスタイルを全点で統一してください。

【スタイル】
・フラットなベクター風のアイコンイラスト
・線画を主体にした、シンプルで清潔感のあるデザイン
・使う色は次の3色のみ：濃紺(#1a1a2e)、赤(#e94560)、白
・グラデーション、影、光沢、質感表現はすべて使わない
・背景は真っ白の単色（透過や模様は不要）
・正方形（1:1）、1024×1024ピクセル
・被写体は中央に配置し、周囲に余白をとる

【絶対に守ること】
・画像の中に文字を一切入れないでください（日本語・英語・数字すべて）
・看板やカレンダーなど文字が入りそうなモチーフでも、文字は書かず、
  線や四角で「文字がある雰囲気」だけを表現してください
・ロゴ、商標、実在する企業やブランドを思わせる要素を入れないでください
・人物を描く場合は、特定の実在人物に似せないでください

準備ができたら「OK」とだけ答えてください。1点目から指示します。
```

---

## 2. 1点ずつ作らせる（6点）

「OK」が返ってきたら、下記を**1つずつ**貼ってください。まとめて貼ると品質が落ちます。

### ① 名刺・チラシ

```
1点目：名刺とチラシ
名刺の束と、A4のチラシが数枚重なっている様子。
文字は書かず、線や四角のブロックで文章や見出しがあることだけを表現してください。
```

### ② 加工

```
2点目：紙の加工
二つ折りにされた紙と、ミシン目の入った紙。
折り目と、点線のミシン目がはっきり分かるように。文字は入れないでください。
```

### ③ Tシャツプリント

```
3点目：Tシャツプリント
ハンガーに掛かった半袖Tシャツを正面から。
胸の位置にプリントがあることを、赤い丸や星などの抽象的な図形で表現してください。
文字やロゴは入れないでください。
```

### ④ 看板・カッティング

```
4点目：看板
自立式の四角い看板と、その横にカッティングシートのロール。
看板の面には文字を書かず、横線を数本引いて「文字が入る面」であることだけを示してください。
```

### ⑤ カレンダー（お日にちの数え方）

```
5点目：カレンダー
壁掛けカレンダーを正面から。
数字や曜日は書かず、マス目だけを描いてください。
そのうち1つのマスに赤い丸をつけて、日付が決まっていることを表現してください。
```

### ⑥ データの受け渡し

```
6点目：データの受け渡し
ノートパソコンの画面から、書類のアイコンが手前に向かって渡されている様子。
画面にもアイコンにも文字は書かず、線と四角だけで表現してください。
```

## 3. うまくいかないときの追加指示

そのまま貼れる修正指示です。

| 症状 | 貼る言葉 |
|---|---|
| 文字が入ってしまった | `画像内に文字が入っています。文字を完全に取り除いて、同じ構図で作り直してください。` |
| 色が多い | `色が多すぎます。濃紺(#1a1a2e)、赤(#e94560)、白の3色だけで作り直してください。` |
| 影や立体感がついた | `影と立体感を取り除いて、完全にフラットなイラストにしてください。` |
| 絵柄がバラバラ | `1点目のイラストと同じ線の太さ・同じ絵柄になるよう統一してください。` |
| 背景に模様が入った | `背景を真っ白な単色にしてください。` |

## 4. できあがったら

1. 6点をダウンロードする（PNG）
2. `intake-rules/img/` フォルダに入れる
3. ファイル名を次のようにする

```
01-print.png    名刺・チラシ
02-finish.png   加工
03-tshirt.png   Tシャツ
04-sign.png     看板
05-calendar.png カレンダー
06-data.png     データの受け渡し
```

4. **Claudeに「イラストを入れて」と言えば、ポスターに組み込みます**

サイズ調整・配置・印刷時の見え方は、こちらで整えます。ChatGPTにレイアウトまでさせる必要はありません。

## 5. 使う前に必ず確認すること

このマニュアルでお客様にお願いしている権利確認は、**自社が作るものにも同じように必要**です。

- [ ] 使っているAIサービスの利用規約で、**商用利用が可能**か確認した
- [ ] 生成された絵に、**見覚えのあるキャラクター・ブランドロゴ・実在の人物**が入っていないか確認した
- [ ] 店頭に貼る前に、社長の確認を受けた

「自分の店のものだから大丈夫」とはなりません。店頭に貼るのは公開と同じです。

---

## 6. 参考：どうしてもポスター全体を作らせたい場合

**おすすめしません。**日本語が崩れ、印刷用の解像度も足りず、直すのに一から作るより時間がかかります。
（まさに、このマニュアルの事例1で起きたことです）

それでも試す場合は、次を守ってください。

- 出てきたものは**そのまま印刷しない**
- **デザイン案として見るだけ**にして、実際の掲示物はHTMLのものを使う
- 文字は必ず全部読んで、1文字ずつ確認する
